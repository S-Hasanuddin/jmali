# RULES.md
# Project Rules & Development Standards

---

# Core Principle

This website represents a real Islamic community organization.

All development, design, content, and branding decisions must prioritize:

- sincerity
- dignity
- clarity
- maintainability
- accessibility
- spiritual atmosphere

---

# Component Rules

## Naming Rules

NEVER use autogenerated names such as:

```tsx
Layout357
Header62
Layout408
```

All components must use semantic names.

Examples:

```tsx
HeroSection
CommunityServices
WeeklyGatherings
NikahSupportSection
OnlineSchoolOverview
```

---

# Content Rules

## Writing Style

All content must be:

- concise
- readable
- human
- sincere
- grammatically correct

---

## Service Clarity

The following MUST remain separate:

### Nikah Services
For couples seeking nikah ceremonies.

### Nikah Assistance for Needy Families
Support for financially struggling families under the broader Nikah Services initiative.

---

# Islamic Sensitivity Rules

Maintain respectful and modest imagery.

Avoid:

- inappropriate photography
- overly stylized portraits
- unnecessary focus on faces
- dramatic commercial aesthetics

---

# SEO Rules

Every page must include:

- unique title
- unique description
- semantic headings
- optimized metadata
- meaningful alt text

---

# Maintainability Rules

Future developers should understand the project quickly.

Code clarity is more important than cleverness.
